[Gentoo Linux] Wireless connection

Quick reference for getting Wi-Fi up on Gentoo without NetworkManager in the picture — useful for headless boxes, minimal installs, or anywhere you just want wpa_supplicant talking directly to the interface.

Execute:

~ # rfkill list ~ # rfkill unblock N

~ # cd /etc/wpa_supplicant ~ # nano wpa_supplicant.conf

~ # wpa_passphrase ESSID password >> /etc/wpa_supplicant/wpa_supplicant.conf

~ # rc-service wpa_supplicant start

How this works:

  1. rfkill list → check for blocked interfaces before doing anything else. rfkill unblock N (N = the interface number rfkill reported) clears a soft block, which is the reason a perfectly good card sometimes just won’t associate.
  2. create wpa_supplicant.conf with:
    ctrl_interface=/run/wpa_supplicant
    update_config=1
  3. wpa_passphrase appends two lines to the file: a commented-out #psk=password line with your password in plain text, and the real psk= line with the computed hash. delete the commented plain-text line and leave the hash — that’s the one wpa_supplicant actually uses. deleting the wrong one breaks the connection, so double-check before saving.
  4. rc-service wpa_supplicant start → brings the connection up under OpenRC.

if it doesn’t associate after this, check dmesg for driver or firmware errors before touching the config again — half the “wpa_supplicant won’t connect” cases on Gentoo are actually missing firmware, not a config problem.

this whole flow assumes you’re managing the interface directly. if you’d rather not deal with wpa_supplicant.conf by hand, NetworkManager or iwd cover the same ground with less manual editing — worth it for a laptop that hops networks, less worth it for a box that connects to one AP and stays there.
