[FIREFOX] ENHANCING PRIVACY ONLINE

this is a set of about:config tweaks for people who want to reduce tracking and fingerprinting in Firefox and are okay trading some convenience for it. it’s not a “flip everything blindly” list — a few of these have a real cost in speed or in sites breaking, so read what each one does before you touch it. if you just want baseline privacy without breaking things, stick to the WebRTC, fingerprinting resistance, and telemetry entries below and skip the rest.

how to open about:config:

type about:config in the address bar and hit enter. Firefox shows a warning screen (“This might void your warranty!”) — click Accept the Risk and Continue. you’ll land on a search bar: paste in the preference name from each item below, and it’ll filter to that single line. for a true/false value, double-click the row to flip it. for a number like the TLS version below, double-click, type the new value, and hit the checkmark to save.

 *********about:config settings start********* 

Disable WebRTC:

WebRTC can leak your real IP even behind a VPN or Tor.

media.peerconnection.enabled = false

Enable fingerprinting resistance:

this alone covers most of what a canvas-blocking extension would do, without adding another extension to fingerprint against.

privacy.resistfingerprinting = true

3DES cipher:

3DES has known weaknesses at this point.

security.ssl3.rsa_des_ede3_sha = false

Require secure renegotiation:

security.ssl.require_safe_negotiation = true

Disable TLS 1.0, 1.1:

security.tls.version.min = 3

Enable TLS 1.3:

security.tls.version.max = 4

Disable TLS 0-RTT for better forward secrecy:

security.tls.enable_0rtt_data = false

Disable form autofill:

browser.formfill.enable = false

Disable disk cache:

this one has a real cost — pages reload slower, sites feel heavier. only worth it if your threat model includes someone getting physical access to the machine and pulling cached data off disk.

browser.cache.disk.enable = false

browser.cache.disk_cache_ssl = false

browser.cache.offline.enable = false

Disable geolocation:

geo.enabled = false

Disable telemetry:

toolkit.telemetry.unified = false

toolkit.telemetry.archive.enabled = false

toolkit.telemetry.shutdownpingsender.enabled = false

datareporting.healthreport.uploadEnabled = false

Disable WebGL:

gives pages fairly direct access to the GPU, and it’s one of the richer fingerprinting surfaces out there. cost: some sites and canvas-based content just won’t render.

webgl.disabled = true

A note on cross-site tracking isolation:

older versions of this list pointed at privacy.firstparty.isolate. current Firefox handles this through State Partitioning by default, so that pref is mostly a no-op now — check about:config for it before relying on it, prefs get renamed or absorbed between releases.

Disable false start on TLS:

security.ssl.enable_false_start = false

Disable script execution by default:

this is the one to think twice about. blocking scripts globally breaks most of the modern web, not just trackers. it’s an extreme-threat-model setting, not a daily-driver one — most people are better served by NoScript or uBlock Origin in a less aggressive mode.

security.default_content_setting_for_scripts = false

*********about:config settings end*********
